# Homebrew tap

Project-maintained cask for [Codex Accounts](https://github.com/braklouis/codex-account-switcher).

```sh
brew tap braklouis/tap
brew install --cask braklouis/tap/codex-accounts
```

macOS 14+ and Apple Silicon required. The app is ad-hoc signed and not notarized. This cask does not bypass Gatekeeper or delete credentials. See the main repository for source, limitations, and security reporting.

Update with `brew update` and `brew upgrade --cask braklouis/tap/codex-accounts`.
